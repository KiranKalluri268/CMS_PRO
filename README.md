# How to Run the Project Locally

To set up and run this project on your local machine, follow these steps:

## Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (latest version recommended)
- An IDE or code editor, such as [Visual Studio Code](https://code.visualstudio.com/)

## Steps to Run Locally

1. **Clone the Repository**  
   Clone this repository to your local machine:
   ```bash
   git clone (https://github.com/KiranKalluri268/CMS_PRO.git)
   ```

2. **Navigate to the Project Directory**  
   Open the project folder in your terminal or IDE.

3. **Install Dependencies**  
   Run the following commands to install all the required dependencies for the project:
   ```bash
   npm install
   cd frontend
   npm install
   cd ../backend
   npm install
   cd ..
   ```

4. **Run the Project**  
   To start the development server, use:
   ```bash
   npm run dev
   ```

Your project should now be running locally.
